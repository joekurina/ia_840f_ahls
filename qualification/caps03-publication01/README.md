# CAPS03 accepted-milestone publication

Each manifest closes only its named accepted gate. The running full-capacity test, mutable GOAL checkpoint, unrelated historical work and raw agent transcripts are excluded. Published files have a2,000,000-byte cap; bitstreams, binary/runtime payloads, embedded-payload launchers and raw transport archives remain local at every size. Exact omitted-file sizes/SHA256 and payload-free metadata preserve provenance without making a replacement executable.

Explicit staged path sets and blob bytes are checked against each manifest. Immutable native capture whitespace is preserved and identified by exact path/hash; authored code/prose must be clean. Each push requires local HEAD, origin/main and remote refs/heads/main agreement. Publication does not execute hardware, replay a launcher or change the active FPGA image.
