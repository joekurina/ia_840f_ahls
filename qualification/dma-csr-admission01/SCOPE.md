# DMA CSR and descriptor admission

Source/native simulation only. Derive from full-top isolate_green01 without modifying its frozen evidence or donor trees. Narrow correction in csr_mgr: reject high/unaligned/unknown CSR addresses, wrong size/partial writes, RO writes; reject raw descriptor field truncation and GO with invalid mode/reserved bits, missing fresh fields, zero/excess length, misalignment, host end overflow, DDR high bits/bank crossing, full queue or existing engine fault. Full 64-bit raw values checked before assignment. Require fresh source/destination/length writes per GO attempt. Return DECERR for decode/access shape, SLVERR for descriptor/admission faults, preserving descriptor values on failed writes. Access-valid field writes rejected for their value invalidate that staging field. Access-valid GO attempts consume freshness, including rejected attempts; address/size/strobe faults leave staging unchanged. Existing accepted queue entries are untouched.

Counter arithmetic bounds admission only, not maximum-length transfer qualification. Full queue is observed with the actual FIFO and a stalled synthetic endpoint; fixture reset afterwards is not live recovery. Good transfers retain prior native data checks. Global control stop/reset semantics, generic AXI4 burst/4KiB behavior, full PIM/AFU/physical DDR/host visibility, and hardware acceptance remain excluded. DDR vendor simulation SKIPPED BY USER. No devices or live FPGA operations.
