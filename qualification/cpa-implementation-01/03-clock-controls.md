# Lane 03 — documented physical clock controls

## Outcome

**`CLOCK_SPINE` is a documented, Agilex-7-supported physical control with a concrete, previously implemented comparison value: EMIF1 uses spine `1` in Work23 but spine `2` in the passing Work21.** Both reports give the same full-device clock region, `SX0 SY0 SX6 SY7`. A future, bounded spine-2 experiment is justified as an implementation experiment, not as a proven remedy or an instruction to run now. It does not require reconstructing the full CPA equation first. Preserve the existing region, clock/interface contract, both DDR banks and PR/static boundaries. [L1, L2][5]

`CLOCK_REGION` is also supported, but **shrinking this particular region is not currently justified**: it belongs to `root_partition`, explicitly supplies the PR Logic Lock region, and spans the full sector grid. `GLOBAL_SIGNAL ON` is not a new optimization: this source is already promoted **Mandatory**. PLL compensation, package-skew and feedback-cut settings are not interchangeable with the CPA compensation term. [L1][5]

**Research only:** GPT-6 / openai-codex substituted for unavailable GLM5.3. No implementation, native execution, source-script/test execution, SSH, hardware or Git mutation. Only this report and `03-requests.json` are written. Independently rechecked all **14/14** file sizes and SHA256s in `evidence-index01.json`; no mismatch. Keep QSF/QDF readback distinct from effective fitted consumption. Reuse lane01/lane02 findings when they supply the same discriminator.
2. **One meaningful physical-dimension trial, if later authorized:** target **A with `CLOCK_SPINE 2`**, keep the region **`SX0 SY0 SX6 SY7`**. The reference recommends pairing spine and region. If baseline has no explicit region assignment, adding that matching companion is a **second assignment record**, not a falsely described one-line patch; it preserves the observed extent instead of testing a shrink. Do not change other clock settings, phase/frequency, memory/PR geometry, vendor RTL or STA requirements. This changes SCLK selection rather than merely trying another seed. It may require allocation changes to the overlapping PCIe spine2 users; inability to fit is a bounded negative result, not permission for a sweep or boundary edits.
   - First require the completed fit's global report to show the intended A/source, spine2 and unchanged extent/ownership, plus no ignored/illegal target. Then compare the exact bit243 all-corner signoff and ordered launch/CPA/data/capture terms, both DDR-bank timing and relevant collateral clock/PR checks. A native command exit or persisted assignment alone is insufficient.
   - Success means positive required timing with unchanged requirements and the retained wider acceptance gates—not a matched old spine, changed COMP, or improvement of only one raw feedback report. No promise of 84ps recovery is made. A changed implementation with unchanged failure closes this one candidate without implying a model bug.
3. **Only if a concrete placement/region rationale emerges:** determine whether any smaller A region can preserve the complete static/PR clock-access contract. The current full-device, root-owned report is contrary to assuming a local-only EMIF clock. No proposed narrower rectangle currently passes that discriminator. Reuse finite region/clock-ownership panels; do not substitute an unbounded `report_clock_network` fanout query, remove required loads, or repurpose the AFU clock to claim a lower EMIF rate.
