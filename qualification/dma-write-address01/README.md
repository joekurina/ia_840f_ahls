# Evidence publication policy

Explicit reviewed milestone allowlist only. Default cap2,000,000bytes. Full donor source copies and payload-bearing run-*.py remain local at any size; their exact bytes are bound by source/dispatch/native-result SHA256 records. Native logs, nonpayload supervisor template, authored patch/test, review and parent acceptance are published. No licensed runtime/installer or license bytes. Preserve hash-bound patch/report whitespace.
