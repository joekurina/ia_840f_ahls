# Evidence publication policy

Explicit accepted-gate allowlist; cap 2,000,000 bytes/file. Preserve full vendor source copies, payload-bearing run-*.py, runtime/precompiled library binaries and any licensed payload locally with SHA256 references. Publish authored tests/patches, nonpayload supervisor/capture scripts, metadata, logs, reviews and parent acceptance. Raw patch/review whitespace is preserved and narrowly hash-audited. No secret/license bytes or internal agent transcripts.
