# AI Suite OFS: FIM/EMIF timing applicability

## Finding

**No directly applicable repair for the supplied Work18 EMIF1 −0.004 ns hold miss was found.** The useful positive result is an inspectable public AFU/build reference and confirmation that its underlying FIM is our existing donor—not a newly qualified Quartus 26.1.1 FIM. The guide explicitly places AI hardware in the AFU, consumes a FIM `pr_build_template`, and emits a green `.gbs` above OFS 2025.1-1.[1]

## Exact tool/version evidence

- **Source requirements:** both `agilex7/iseries_ofs_pcie/README.md` and `agilex7/n6001_ofs_pcie/README.md`, at AI tag `rel-2026.1.1` / `e0e07f7b1878a477dc4d1191918db8430193e148`, require **AI Suite 2026.1.1 + Quartus Prime 25.1 + OFS 2025.1-1 slim FIM**.[19][20]
- **Vendor FIM release:** OFS 2025.1-1 specifies **Quartus Pro 25.1; patches: None**. Its FIM commit is `599ac052eafbc9cede22561c099233ae4a54cb7d`; the inspected tree pins `ofs-common` to `34a8540697fdf3d66fbcaa263fa037bae17cc32f`, exactly the supplied maintained baseline.[3]
- **Documentation disagreement:** AI Handbook §4.2.5 gives general Linux compatibility **24.3–26.1**, but Table 13 says **24.3** for I-series OFS and **25.1** for N6001. The I-series 24.3 entry was verified in the rendered HTML table, not inferred from a malformed extraction; it conflicts with the pinned example README and FIM release.[29][19][3]
- **26.1.1 distinction:** Quartus 26.1.1 release notes explicitly bundle AI Suite 2026.1.1. This establishes distribution availability, **not qualification of the 25.1-built PR template or IA840F on 26.1.1**.[6] Preserve selected Quartus 26.1.1/AHLS 2026.1/examples-OFS 2026.1; no downgrade follows from this research.

## What the inspected source actually supplies

`setup_project.sh` invokes `afu_synth_setup` and deploys `dla_afu`; `ofs_build_env` resolves the supplied FIM template and its build tools. These are AFU integration, not a replacement EMIF generator or physical hold repair.[24][26]

The pinned FIM's I-series and N6001 `syn/board/*/syn_top/ofs_top.qsf` use `ALLOW_REGISTER_RETIMING ON`, `OPTIMIZATION_MODE "SUPERIOR PERFORMANCE"`, and maximum router timing optimization; both record Quartus 25.1.0. These are existing donor settings, not a new exact-bit retiming workaround.[10][11]

Inspected `syn/shared_config/top.sdc` contains derived uncertainty, clock-domain separation, PCIe multicycles and memory reset/calibration synchronizer constraints—not an EMIF1 UFI data-delay repair.[7]

`ipss/mem/qip/mem_ss/README` explicitly says board-specific IP is generated by OFSS during configuration.[15]

Also inspected: both boards' `quartus.ini`, I-series `emif_rdimm_loc.tcl`/`pr_assignments_slim.tcl`, N6001 `emif_loc.tcl`, `ipss/mem/mem_design_files.tcl`, common `tools/ofss_config/memory_ip.py`, and AI `dla_platform.qsf`/`afu_ip.qsf`. No new fix for `FORCE_HYPER_REGISTER_FOR_CORE_PERIPHERY_TRANSFER`, `HYPER_REGISTER_DELAY_CHAIN`, or the supplied five-corner miss appeared in these files; captures preserve their exact bytes. This is a **bounded source finding**, not proof that no vendor fix exists anywhere.

AI release notes identify **embedded-memory corruption during partial reconfiguration**, with reprogram/reboot recovery. That is not a static EMIF hold-timing fix; no recovery was executed.[2] Quartus 26.1.1 lists incorporated patch numbers/case IDs without descriptions tying them to this failure.[6]

## Acquisition and reuse boundary

- Public AI source: official GitHub tag below; inspect `agilex7/{iseries,n6001}_ofs_pcie/` without downloading the SDK.[30]
- FIM source and published slim-image packages: OFS release below. Guide links `iseries-dk-slimfim-images_ofs-2025-1-1.tar.gz` and `n6001-slimfim-images_ofs-2025-1-1.tar.gz`; these contain the foreign-board baseline/template, not an IA840F repair.[1][3]
- Reuse **source patterns only**. Guide memory configurations are four 8 GB I-series banks or four 4 GB N6001 banks—not our two 16 GiB ×64 channels.[1] Preserve AGFB027R25A2E2V, discrete ch0/RDIMM ch1, P-tile Gen4×16 endpoint, expected host Gen3×16, and no UART/HPS. Do not borrow SOFs, pins, PR regions or geometry.

Five focused searches; only documentation/metadata/small sources acquired. No builds, installations, remote/hardware operations or repository edits. Evidence and citation ledger: `timing-captures/`. Oversized presets and binary packages were not downloaded; no timing acceptance is claimed.
