Scope is local authoring of the guard component only, not an assembled or prepared A/B package. No native/remote/hardware authorization. The accepted [source disposition](../native-mapping-disposition03.md#b-correct-the-actual-creation-guard-not-just-the-downstream-collector) and [diagnostic03 result](../fanout-diagnostic03/RESULT-ACCEPTANCE.md) support this narrow intervention. Do not require a proven native insertion-time result before reviewing the component; that state must be measured and rejected if unexpected in the later reviewed experiment.

1. Preserve original helper bytes/functions. Add `apply_v2`, `verify_created_v2` and prefixed supporting locals; no original/vendor array mutation.
2. Retain exact D/I/O/M/C identities, direction/type/cardinality and physical source checks. Record/flush counts before assertions. Distinct collection/object handles; no guessed APIs or escaping change.
3. At insertion, require absent C name, no explicit definition targeting O/K, exact upstreamM output-driving association, and expected M target; an association is not a definition. Unexpected state fails before create.
4. Execute exactly `create_generated_clock -name $C -source $I_collection -master_clock $M -divide_by 2 $O_collection`; no -add/nominal clock/phase/offset/inversion or fallback. Single use, created flag retained on later failures.
5. Snapshot bounded global definitions before/after and after full SDC; require exactly C added and all other definitions unchanged. Base clock inventory must not query generated-only properties. Global clock cap256; definition target cap4096; raw counts/uniqueness checked.
6. Postcheck requires generatedC, exact sourceI/targetO/immediate masterM, returned integer divide2/multiply1, not inverted, actual period/waveform consistent with unshifted divide2 and output association exactlyC. Log native edge/shift metadata for later independent interpretation. Unexpected ratio representation fails, not guessed conversion. Require returned decimal timing precision of at least three fractional digits and use half-quantum bounds from actual returned precision, not a nominal period. This is a proposed finite acceptance rule, not already observed candidate-native data.
7. Tests must demonstrate old guard rejects measured upstream association without a definition, new guard accepts it, precondition faults create nothing, postcondition faults reject after one creation, rounding is accounted for, and repeats reject. Tests use local Tcl and distinct synthetic object/collection handles only; not vendor emulation/native success.
8. Other A/B query/runner/gate/preparation work remains unfinished and separately gated. This component review approves no future issuer or assembled package. No source promotion, timing/collector/hardware qualification or task closure.
