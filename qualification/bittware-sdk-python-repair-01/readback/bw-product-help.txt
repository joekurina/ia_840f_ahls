usage: bw_product [-h] [-l] [-d] [--version] [-L {INFO,DEBUG}]
                  [product_name ...]

Product Utility

positional arguments:
  product_name          A string that selects the target product. This string is lazy
                        matched (case ignored) to known product names. The default value is 'ALL'
                        which lists all known products.
                        
                        The product name may be followed by one or more attribute names, in
                        which case the specified product attributes are listed.Valid attribute names are:
                        
                        alt_mfg_info
                        bmc_class
                        bmc_handler
                        bmc_type
                        card_desc_path
                        clock_files
                        data_directory
                        dump
                        family
                        fpga_desc_path
                        name
                        prom
                        str_family
                        str_name
                        test_plans
                        vendor_info

optional arguments:
  -h, --help            show this help message and exit
  -l, --list            List product(S), short form
                        
  -d, --dump            List product(s) long form (dump)
                        
  --version
  -L {INFO,DEBUG}, --loglevel {INFO,DEBUG}
                        Log level to log (INFO, DEBUG) defaults to None

    Tool for finding info for installed products.

Typical use:
    $ python -m bw_core.product -d
        < Dump long form product info for all products >

    $ python -m bw_core.product -l ia440
    IA-440I          /home/dbelser/SDK3/REPOS/Product_Families/agilex/bw_agilex/data/IA-440I

    $ python -m bw_core.product ia440 alt_mfg_info
    alt_mfg_info:{'Model': 'IA-440I'}
