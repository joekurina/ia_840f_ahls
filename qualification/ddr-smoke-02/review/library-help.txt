vdir Usage: vdir -help|-usage           
       vdir [-l | [-prop <prop>]] [-r] [-obj] [-all | [-lib <path>]] [-libversions]                 
          [-ini <ini_filepath>]         
          [[-language <language>] | [-dukind <dukind>]]                         
          [<primary>]                   
       where <prop> is one of           
            archcfg:    Block configuration applies to architecture             
            body:       Needs a body    
            cmpltime:   Compile time    
            coemm:      specified property for Cell OEM Marking                 
            default:    Compile defaults
            dir:        Source directory                                        
            dpnd:       Depends on      
            entcfg:     Configuration applies to entity                         
            fulloptions:        Full compile options                            
            inline:     Module inlined  
            lock:       Design unit locked/unlocked                             
            lrm:        VHDL language standard                                  
            mtime:      Source modified time                                    
            name:       Short name      
            opcode:     Opcode format   
            options:    Compile options 
            pdu:        Preoptimized design unit                                
            prot:       Design unit involves at least one protected code region 
            root:       Optimized Verilog design root                           
            src:        Source file     
            signature:  Source File Signature                                   
            top:        Top-level model 
            vdpnd:      Depends on Virtual Interface                            
            ver:        Version string  
            vlogs:      Verilog source version                                  
            vlogv:      Verilog version 
            voptv:      Verilog optimized version                               
       where <language> is a comma-separated list with                          
            verilog 
            systemverilog               
            vhdl    
            systemc 
            verilogams                  
            vhdlams 
       where <dukind> is a comma-separated list with                            
            (---- Verilog ---)          
            module  
            program 
            vlconfig                    
            vlpackage                   
            udp     
            interface                   
            (----- VHDL -----)          
            entity  
            vhpackage                   
            vhconfig                    
            context 
            (---- SystemC ---)          
            systemc 
            (--- Ams Verilog ---)       
            moduleams                   
            vlpackageams                
            (--- Ams VHDL ---)          
            entityams
